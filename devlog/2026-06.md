## 2026-06-03 — iOS: PersonalizationEngine, DeckLabelsStore, Midnight Tags

### New files
- `DeckLabel.swift` — Model decoding `deck_labels.json`. Struct with `deckKey`, `labelColor`, `labelTextColor`, `highlightTags` array of `TagEntry`. `_ref` field ignored by Codable.
- `DeckLabelsStore.swift` — Bundle on init, then cache, then CDN fetch async. Singleton. `label(for: deckKey)` lookup.

- `midnight_pick` added (Mon–Thu 22:00–01:59): Weeks Apart, Good Nights, Slow Down
- `midnight_weekend_pick` added (Fri–Sat 22:00–02:59): Hot Takes, Game On, Play & Nostalgia

## 2026-06-04 — iOS: Widget Updates + Watch Font Size

### What was changed
- `WQuestion` struct updated to decode `widget_eligible` field from `questions.json`. `loadAll()` filters to eligible questions only (161 of 2,399).
- Large widget layout: replaced `VStack + Spacer + padding(.bottom)` with `ZStack(alignment: .bottomLeading)`. Root cause: iOS 17+ `containerBackground` safe area unreliable for padding above ~12pt on large widgets.
- Small widget label: `"Your daily question"` → `"Your daily Q"` in small views only
- 6 background image sets added to widget assets: `WidgetBgDarkSmall/Medium/Large`, `WidgetBgLightSmall/Medium/Large`
- Watch font sizes: question text `.body` → `.headline`, deck name `.footnote` → `.subheadline`

### Variable font weight on device (unresolved)
The `inter()` helper applies wght axis via `UIFontDescriptor` and `kCTFontVariationAttribute`. Works in simulator, not on device. Attempts made: explicit `NSNumber(value: Int32(bitPattern: 0x77676874))` key, `CTFontDescriptorCreateCopyWithVariation`. None resolved it. Current state: `UIFontDescriptor` approach kept with comment. **Known fix: use static Inter weight files instead of the variable font.**

### Files changed
- `QwavaWidget.swift` — `widgetEligible` field, `loadAll()` filter, ZStack large layout, small label text, image background support

### QwavaApp.swift fix
- `qwava_first_open_date` was initialised inside async Task's do block. If manifest fetch threw, the date was never set. Moved to synchronous `init()` before the Task.

### Sort menu checkmarks
