## 2026-05-28 — iOS: Widget Extension + App Store 1.2.0 Submitted

### What was built
- New `QwavaWidget` target: Widget Extension, no Configuration App Intent
- `QwavaWidget.swift`: `WQuestion` struct decoding only `question` field from `questions.json` (local bundle, no network). Daily question selected deterministically by date seed: `(year - 2024) * 366 + day` modulo total count.
- Three sizes: small, medium, large. `contentMarginsDisabled()` for full padding control.
- Two variants: `QwavaDarkWidget` (`Color("PrimaryDark")` background) and `QwavaLightWidget` (`Color(.systemBackground)`, adapts to dark mode). Both in `QwavaWidgetBundle` with `@main`.
- `Font.inter(size:weight:)` helper: loads `UIFont(name: "InterVariable", size:)`, applies wght axis via `CTFontVariationAttribute` with tag `2003265652`. SwiftUI `.weight()` modifier does not work on variable fonts in widgets.
- `Inter-VariableFont_opsz,wght.ttf` added to widget target membership and declared in widget `Info.plist` under `UIAppFonts`

### App Store v1.2.0
- Version bumped to 1.2.0 across all three targets
- 10 screenshots (8 existing + watch + widget)
- Submitted and approved

### Key decisions
- No App Group needed; widget reads from local bundle only
- Deck name removed from widget; "Your daily question" used instead
- Two widget configurations in a WidgetBundle; `@main` on the bundle

### Files changed
- `QwavaWidget.swift` — New file in QwavaWidget target
- `QwavaWidget/Info.plist` — `UIAppFonts` array added
