## 2026-03-15 — iOS: Content Architecture, Data Pipeline, Filter System, Depth Filter, v1.1.0 Submitted

### Data model decisions
- Three-file model: `questions.json`, `decks.json`, `deck_filters.json`
- `deck_filters.json` is the single source of truth for audience, closeness, category, depth_default
- `decks.json` contains visual data only (label fields removed)
- Depth and vibe are question-level fields; audience, closeness, category are deck-level
- `deck_filters.json` stores pipe-separated values; `DeckFilterStore` splits on pipe at runtime
- Local bundle is always the fallback; CDN version replaces it at launch if available

### What was built
**DeckFilterStore.swift** — Fetches `deck_filters.json` from CDN, applies values to each deck via `applyFilterOverride`. Runs outside the manifest do/catch block so it always fires at launch.

**In-session depth filter** — Half sheet triggered from filter icon in `QuestionPlayerView` top-right. Depth toggles default to each deck's `depth_default`. Reset returns to deck recommendation. Apply rebuilds the question pool.

**QuickMix fixed** — Vibe and mood removed. QuickMix now filters decks by audience and closeness, then questions by depth.

**FiltersView** — Depth and Vibe sections removed. Audience, Closeness, Category only.

**Questions** — App now loads from `questions.json` (1,794 questions). Old CSV deleted.
