# Qwava Dev Log

Technical development log for [Qwava](https://qwava-app.com), the conversation card app.

## What this repo is

A reference document for every meaningful technical decision made during development. Entries describe what changed, which files were affected, why decisions were made, and what was fixed or built. Written to be useful when returning to a file weeks later.

## What this repo is NOT

- No API keys, tokens, or credentials of any kind
- No Firebase project IDs, CDN paths, or bundle identifiers beyond what is already public
- No business strategy, pitch content, investor materials, or product roadmap
- No personal data of any kind

That information lives in private Notion workspaces.

## Structure

```
/devlog/
  2026-03.md
  2026-04.md
  2026-05.md
  2026-06.md
```

One file per month. New entries are appended at the bottom of the current month's file at the end of each session.

## Platforms

- iOS (Swift, SwiftUI, Xcode)
- Android (Kotlin, Jetpack Compose, Android Studio)
- watchOS (SwiftUI)
- iOS Widget Extension (WidgetKit)
